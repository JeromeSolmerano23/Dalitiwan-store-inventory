DALITIWAN STORE – INVENTORY MANAGEMENT SYSTEM
Frontend-only static website.

HOW TO RUN
1. Extract the ZIP file.
2. Open the dalitiwan_store folder.
3. Double-click index.html, or open it with Chrome/Edge.
4. Use the sidebar to navigate between Dashboard, Products, Inventory, Reports, and Store Information.

NOTES
- No backend, database, API, or real authentication.
- Product edits and stock changes are saved in the browser using localStorage.
- Data is sample/demo data. Clearing browser site data resets it.
- Google Fonts require an internet connection; system fonts are used as fallback.
